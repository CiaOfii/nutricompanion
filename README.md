# NutriCompanion 🥗

**NutriCompanion** adalah aplikasi web edukasi gizi yang membantu pengguna memperoleh informasi seputar pola makan sehat, kebutuhan gizi, dan edukasi nutrisi melalui antarmuka web serta chatbot berbasis Gemini API.

## ✨ Fitur

- **NutriBot AI** — chatbot edukasi gizi berbasis Gemini API.
- **Kalkulator Gizi** — akses fitur perhitungan gizi yang tersedia pada aplikasi.
- **Kalkulator KPSP** — fitur terkait pemantauan perkembangan anak.
- **Isi Piringku** — edukasi mengenai pola makan seimbang.
- **Artikel Edukasi** — informasi seputar gizi dan kesehatan.

## 🛠️ Teknologi

- HTML
- CSS
- JavaScript
- Node.js
- Gemini API

## 🚀 Menjalankan Secara Lokal

1. Pastikan Node.js sudah terpasang.
2. Clone repositori ini:

   ```bash
   git clone https://github.com/CiaOfii/nutricompanion.git
   cd nutricompanion
   ```

3. Pasang dependensi:

   ```bash
   npm install
   ```

4. Buat file `.env` berdasarkan `.env.example`, kemudian isi konfigurasi API sesuai kebutuhan aplikasi.

5. Jalankan server sesuai script yang tersedia pada `package.json`:

   ```bash
   npm start
   ```

6. Buka alamat lokal yang ditampilkan oleh server di browser.

## 🔐 Keamanan

- Simpan Gemini API key di environment variables.
- Jangan mengunggah file `.env` yang berisi kredensial asli.
- Jangan menaruh API key rahasia di kode frontend.
- Gunakan `.env.example` untuk mendokumentasikan nama variabel yang dibutuhkan tanpa mencantumkan nilainya.

## 🎯 Tujuan Proyek

Proyek ini dikembangkan sebagai media edukasi gizi berbasis web sekaligus sarana pembelajaran pengembangan aplikasi, integrasi API AI, pengelolaan konfigurasi server, dan deployment.
